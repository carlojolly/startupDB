# Definition of done (UI)

**Source:** `source:our-skill`  
Shared backend gates also live in `../../backend-engineering/references/definition-of-done.md`.

## UI approved

All must be true (or explicitly waived in `decision.md` with reason + timestamp):

- [ ] Screen inventory complete; every listed screen exists
- [ ] Design checklist (`design-checklist.md`) passed
- [ ] A11y + responsive review (`a11y-responsive.md`) passed
- [ ] No provenance ids with status `rejected` used
- [ ] Components tagged in `agents.md` with `provenance_id` + `source`
- [ ] Material UI decisions logged in `decision.md`
- [ ] Companion checks when installed:
  - [ ] Impeccable critique/audit/polish and/or `impeccable detect`
  - [ ] Taste Skill browser gate for marketing pages
- [ ] User sign-off on the visual direction

Then create/update `context.md`, `decision.md`, `agents.md` and hand off to backend engineering.
